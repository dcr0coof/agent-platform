# Triage label mapping

Inspect remote labels before applying or creating labels. Until remote access succeeds, the following is a proposed mapping, not a claim that the labels already exist.

| Role | Preferred label |
| --- | --- |
| Bug | bug |
| Feature | enhancement |
| Needs evaluation | needs-triage |
| Needs information | needs-info |
| Ready for implementation | ready-for-agent |
| Requires human action | ready-for-human |
| Will not implement | wontfix |

Use one category and one triage-state label when performing triage. Mark future dependent issues as blocked in their body rather than pretending all work can start immediately.
