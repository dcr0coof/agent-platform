# 出行日期日历草稿

在工作台保存开始和结束日期后，点击「下载出行日历」，再自行导入个人日历。只生成一个全天事件，标题、出发地、目的地来自当前已保存出行；不导出聊天、预算、偏好或未发送草稿。

事件标记为暂定、空闲和私人，说明中明确它不是预订或已确认行程。开始/结束日期均为旅行范围的包含日；文件中的 DTEND 是结束日期次日，不使用时区或午夜时间。跨年与闰日按 UTC 日期计算。日期缺失、无效、倒序或次日超出四位年份时拒绝导出。

文本转义、CRLF 行尾、UTF-8 字符边界和每行最多 75 字节的折行遵循 [RFC 5545 §3.1、§3.3.11、§3.6.1](https://www.rfc-editor.org/rfc/rfc5545)。用户文本不能注入额外事件或属性。UID 在同一出行内稳定，但重复导入如何处理由日历应用决定。

本功能不接入远端日历、不发送邀请、不创建预订。草稿修改未保存、请求进行中或运行未结束时按钮禁用。已验证文件内容和真实浏览器下载；尚未实测各厂商日历的导入界面。日历应用可能自行调整隐私或忙闲展示，导入后请核对。
