# 查看本次运行的上下文

发送请求后，输入框上方可展开「本次运行用了哪些上下文？」。内容来自当前运行的 context.ready 事件，与执行过程共用已有记录；可通过键盘操作，刷新后读取持久化记录，切换出行或开始新运行不会沿用旧运行的内容。

真实运行的记录说明最初请求加载的历史消息/完整回合与字节边界。它不代表全部已保存历史，不计本轮输入与系统约束，也不是 token 数、剩余模型额度或后续工具调用用量。演示模式只展示演示记录，不冒充真实模型上下文。

没有事件时明确显示尚无可用记录，不能推断为零历史。若存在未载入历史，旧记录仍保存在出行中；用户需要重新提供当前回答所需的旧信息，并把重要条件确认保存到出行约束。这个面板不执行摘要、恢复或更改上下文策略。

界面使用原事件文字，不从中文描述反推结构化指标。已有历史窗口和请求大小检查维持不变。真实模型是否遵循这些说明仍需要真实配置联调。
