# ADR 0001：本机出行工作台与持久运行模型

状态：已采用（Issue #3）。日期：2026-09-06。

## 问题

CLI 已有完整回合记忆与工具调度，但浏览器无法创建出行、修改条件、取消请求或在重启后继续聊天。首个作品集演示需要一条可复现的完整路径，且不能为了前端演示强制购买 API 服务或配置数据库集群。

## 决定

复用 Go Agent，增加 HTTP 服务及 Vue 3 / TypeScript 界面。使用 `modernc.org/sqlite`，保持 Go 1.22、Windows 和无 CGO 环境可用。SQLite 使用 WAL、单连接和事务。每个数据库文件只由一个服务进程使用；目前没有跨进程锁或任务租约，不能让不同端口的实例共享文件。

`sessions` 保存归属、已确认约束、版本号和完整成功历史；`runs` 保存任务输入、幂等键、状态和错误；`events` 保存有序操作事件。数据库中的完整历史与发送给模型的近期完整回合窗口分开。用户在聊天中提出的偏好变更不会被静默写成表单中的已确认条件。

每个会话最多一轮活动任务，整个服务最多四轮。开始与编辑通过版本号拒绝过期写入。`(session_id, request_id)` 唯一；相同输入重试返回原任务，不能因 SSE 断线再次执行模型或工具。成功回合、终态及最后事件在同一事务提交；取消或失败只记录运行，旧聊天不变。取消与完成串行判定，迟到事件不再写入。进程重启将遗留活动任务标记失败，不自动重放潜在工具副作用。

SSE 输出实际的上下文准备、模型请求、工具调用及终态事件，可从序号续读。不输出模型内部推理，也尚未实现回答文本的 token 流。

服务仅监听回环地址。随机 HttpOnly、SameSite Strict Cookie 的摘要作为归属标识；全部会话、任务和事件读取检查归属。Host 和 Origin 限制本机页面访问。此隔离适用于本机浏览器体验，不能作为公开服务的账号认证。数据库文件未加密；具有文件系统权限的人可读取数据。清理 Cookie 会失去对应界面访问能力。

演示模式必须显式传 `-demo`，界面和回复持续标记。该模式只检查输入条件，不伪造真实模型、天气、路线或报价；真实模式沿用已配置的模型及工具。

## 取舍与后续

SQLite 减少演示部署依赖，代价是单服务写入、没有多实例调度和完整迁移框架。多用户公开部署需要账号、授权、额度与运维措施；届时评估 PostgreSQL 和任务租约。文档及向量存储由 Issue #5 处理，不为了展示 RAG 而先引入空检索层。

当前消息数窗口是软限制；完整历史长期增长，未提供 token 预算、摘要或清理策略。这些由 Issue #6 处理，不能把持久化等同于已完成长上下文管理。

## 验证

Go 测试覆盖持久化恢复、版本冲突、幂等请求、浏览器隔离、取消、失败不写历史、完整工具回合与 SSE 续读。Playwright 覆盖编辑后继续对话、刷新恢复、独立浏览器与移动端。真实付费 Provider 调用不作为自动化测试前提。
