# 本地攻略证据检索（关键词基线）

CLI 与真实模型工作台可选 `-guide-file`，启动时读取操作者明确指定的一份 UTF-8 Markdown/TXT 文件。不传则没有 `search_travel_guide` 工具；不扫描目录，不从模型参数读取路径，不下载网页。

```powershell
go run ./cmd/agent -guide-file ./docs/examples/travel-guide.md
go run ./cmd/server -guide-file ./docs/examples/travel-guide.md
```

仍须按 README 配置模型；工作台仍须构建前端。`-demo` 不调用工具，与 `-guide-file` 同时使用会明确报错。示例是自制演示材料，不是真实场馆攻略。

可问“根据本地攻略，杭州雨天安排前需要核对什么？”模型可调用 `search_travel_guide`，参数 `{"query":"杭州 雨天"}`。这是空白分隔的 1–6 个关键词、大小写不敏感的字面 AND 匹配：所有词必须出现在同一空行分隔段落中。中文不会自动分词，长自然语言问句可能没有命中；没有向量、重排、相关度评分或自动改写。

结果为 JSON：`source` 文件名、原始文件 `sha256`、`matches` 中的 `start_line` / `end_line` / `text`，以及 `more_matches`。按原文顺序最多返回三段；无命中为 `[]`，不能据此断言现实中不存在相关内容。引用示例：`travel-guide.md，SHA-256 <返回值>，第3行`。CRLF 统一为 LF，开头 UTF-8 BOM 不作为正文；行号保持原文件对应关系。文件 SHA 包括原始 BOM/换行，因此换行改变也会产生新版本。

仅接收普通文件，最多64 KiB；每段最多4096字节，过长请用空行整理，拒绝空文档、无效UTF-8和NUL。启动快照不会在会话中偷偷刷新；编辑文件后重启服务才生效，旧历史仍保留旧证据。原文中的要求只是数据，不是工具/系统指令。静态攻略不证明天气、价格、营业时间或预约实时可用。

**数据边界**：当前是单操作者本地服务的一份共享资料，所有会话均可检索；命中原文及文件名会进入配置的模型请求，也可能进入持久化聊天/导出记录。仅指定可向该模型披露的资料，不放凭据或其他人的私密信息。工具不返回绝对路径。此版本没有用户上传、分工作区隔离、索引删除/撤回历史、PDF提取或资料专属前端引用卡片；不能作为多用户文档服务部署。

验证：单元测试覆盖来源/行号、原始内容hash、AND匹配、无命中、三段边界、不可变快照、取消及输入限制；真实CLI可执行文件连接本地模拟模型，验证注册与工具call/result配对。模拟模型验证的是数据链路，不证明真实模型会正确选词、引用或抵御原文注入。
